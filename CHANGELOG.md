# Changelog

All notable changes to this project will be documented here.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [0.1.0] - 2026-05-08

### Added
- FastAPI server with REST endpoints for mining, entropy, and missions
- Live TUI dashboard via Textual
- SQLite-backed persistent game state via SQLModel
- Tier progression system (Tier 0 → Tier 1)
- Entropy mechanic with risk zones
- Mission engine
- `scriptrunner start` CLI command
- Starter script and player guide
